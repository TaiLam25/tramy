# Cây Hoa Anh Đào Lãng Mạn - Cảm Ơn Em Yêu 🌸

Website 3D tương tác lãng mạn viết bằng **Three.js**, **GSAP** và **HTML5/CSS3**.

## ✨ Tính năng nổi bật
- Cây hoa anh đào (Sakura) 3D phong cách anime/cinema với cành uốn lượn tự nhiên.
- Hiệu ứng bão cánh hoa 3D (InstancedMesh, 60 FPS) bao phủ toàn màn hình khi người dùng chạm vào cây.
- Lời nhắn cảm xúc hé lộ với hiệu ứng blur-to-focus:
  > **“Không phải là 20/10 mà là cảm ơn em yêu đã mua trà sữa cho tui hôm nay nhé”**
- Ly trà sữa bồng bềnh với trân châu và ánh sao lấp lánh.
- Hệ thống âm thanh Web Audio API (chuông pha lê, đàn hạc, không cần file ngoài).
- Nút "Xem lại 🌸" cho phép phát lại toàn bộ trải nghiệm bất cứ lúc nào.

## 🚀 Hướng dẫn deploy lên Vercel
1. Tạo một repository mới trên GitHub (ví dụ: `tra-sua-cho-em`).
2. Liên kết remote và push:
   ```bash
   git remote add origin https://github.com/<username>/<repo-name>.git
   git push -u origin main
   ```
3. Truy cập [Vercel.com](https://vercel.com) -> **Add New Project** -> Chọn repository vừa push -> Nhấn **Deploy** (không cần cấu hình build command hay output directory).
